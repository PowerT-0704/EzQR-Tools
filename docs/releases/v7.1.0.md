# 易码 EzQR-Tools v7.1.0

文本默认本地生成，断网也可生成并保存 PNG。图片解析仍需草料接口，本地解码留到 v7.2。

## 主要变化

- 主进程新增统一编码引擎及 qrcode 本地适配器，文本生成与重构后编码默认离线完成。
- 设置中可手动切换本地/草料生成，并调整 128–4096 像素、L/M/Q/H 纠错、0–16 模块边框。
- 默认仍为 1024×1024 PNG、M 纠错、2 模块边框。
- 保留中文、URL、多行、emoji 及首尾空白；移除旧的 900 字警告和 2000 字导入限制。
- 950 个常见汉字用 L 纠错验收；容量不足或输出尺寸过小时明确报错，不自动改变纠错或上传内容。
- 每次生成和重构使用当前参数快照，避免设置延迟保存时误用在线引擎。
- 启动不再自动请求草料生成探针；手动接口检测及 GitHub 静默更新检查保留。
- 旧配置缺少引擎选择时默认本地，历史、保存目录与界面材质继续兼容。

## 能力边界

- 图片解析仍会上传草料；本地生成不需要接口密钥，也不会在失败时自动联网重试。
- 单个二维码容量随编码模式和纠错级别变化，超过 900 字符并不代表任意内容都能装入。
- 0 模块边框可用于受控排版，独立扫码时建议保留白色留白。
- 安装器未数字签名，Windows SmartScreen 可能显示提示。
- 配置和历史默认保存在安装目录下的 `config`；卸载前应备份。

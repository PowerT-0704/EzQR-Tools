# 易码 EzQR-Tools v7.4.0 交付与验收

验收日期为 2026-11-15。v7.4.0 增加透明 PNG 和可缩放的 SVG 路径。

下载和发布说明见 [GitHub Release](https://github.com/PowerT-0704/EzQR-Tools/releases/tag/v7.4.0) 与 [易码官网](https://w3f7-ezqr-tool.netlify.app/)。

## 功能与使用

- 「文本生成」「图片重构」在开始前选择白底 PNG、透明 PNG 或 SVG。默认白底 PNG。草料引擎只提供白底 PNG，切换到本地引擎后可使用另外两种格式。
- 「透明与矢量」支持选取和拖入 PNG。白底转透明、透明转 SVG 可以分别完成，白底也可以直接转 SVG。当前透明结果可接着转矢量。独立转换在用户另存时写出文件。
- 透明 PNG 仅显示实心黑块，其余像素全透明。独立转换保留输入画布、偏移、留白和黑块轮廓。集成 SVG 直接根据二维码模块生成封闭路径，二维码尺寸设置决定其默认显示尺寸。
- 棋盘格属于预览。生成预览与保存绑定同一结果，重构的新格式文件同名时自动编号。独立转换另存时保护原图路径，包含省略扩展名的情况。

## 验证结果与限制

- 类型检查、Lint、109 项单测及差异检查通过。NSIS 构建成功。ASAR 内 zxing-wasm 3.1.6、WASM 哈希、第三方许可和主进程语法检查通过。
- 最终 Electron 回归 28 项全部通过，其中 27 项应用测试和 1 项实际打包版测试。打包版确认应用版本 7.4.0 和 Electron 44.9.1，断网完成三种独立转换、生成 SVG、重构透明 PNG 及原有解析、重构和保存。早期回归的测试定位与断言已修正，最终运行通过。
- 透明 PNG 验证了不透明黑块和全透明背景。独立转换使用带偏移的非正方形测试图，逐像素核对尺寸、位置和留白。SVG 由 Chromium 渲染后铺白底，再用 jsQR 验证中文、表情、多行和首尾空白。
- 独立转换支持纯黑白 PNG 或纯黑加全透明的 PNG。灰边、彩色和半透明图片可先经过图片重构。沿用输入大小和尺寸限制，SVG 最多 10 万个合并矩形。透明二维码应贴在浅色底面上并保留留白。
- 生产依赖审计报告 fast-xml-parser 1 项低危告警。该告警需要启用非默认的 stopNodes，当前文档导入配置不使用该选项。全依赖审计另有 12 项中危告警，由开发工具的 minimatch 依赖传递而来。本轮复用现有依赖版本。[fast-xml-parser 告警详情](https://github.com/advisories/GHSA-474x-hrwr-fgx4)
- 安装器沿用未签名方式。打包版从便携目录启动验收，NSIS 安装和卸载向导未运行。

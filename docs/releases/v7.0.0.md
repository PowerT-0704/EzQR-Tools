# 易码 EzQR-Tools v7.0.0

易码 EzQR-Tools 的首个 GitHub 公开版本。

## 主要功能

- 拖入或选择二维码图片，解析内容并重新生成高清二维码。
- 输入文字、链接或多行内容生成二维码，并保存为 PNG。
- 支持 TXT、Markdown、JSON、Word、ODT、RTF 等文本文件导入。
- 独立历史记录弹窗，支持回填内容和打开已保存文件。
- 浅色 Plasma 液态玻璃界面，提供晨雾蓝、樱花粉和薄荷青三种氛围。
- 启动时静默检查 GitHub Releases，在软件设置中提示可用新版本。

## 下载

- Windows 10/11 x64 安装器：`EzQR-Tools-7.0.0-x64-Setup.exe`
- SHA-256：`D3AE3BC08AE7ED0CA7CC6613240EE4E9C735507F43630E385C93B3D07EC9C243`

## 安装说明

1. 下载并运行 Windows x64 安装器。
2. 选择安装目录和需要的桌面、开始菜单快捷方式。
3. 启动程序后即可拖入图片或切换到文本生成。
4. 在“软件设置 → 数据与关于”中检查 GitHub 最新版本。

## 注意事项

- 本轮安装器未进行数字签名，Windows SmartScreen 可能显示安全提示。
- 安装器和程序仅支持 Windows x64。
- 配置与历史默认保存在程序安装目录的 `config` 文件夹，卸载前请先备份。
- 当前图片解析与二维码生成依赖草料开放接口，离线二维码内核仍在规划中。
- 更新检查只提示并打开 GitHub Release，不会自动下载或安装新版本。
- 项目官网尚未上线；源码、问题和版本发布统一使用 GitHub。

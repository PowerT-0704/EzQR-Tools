# 易码 EzQR-Tools v7.3.0

新增独立“二维码解析”：只在本机读取图片内容，不重构、不保存新图片、不写历史。

## 变更

- 左侧第三个工作区支持选择、拖入、原图预览，多码按位置全部展示并逐条复制，保留首尾空白与重复内容。
- 即使全局处理引擎选择草料，独立解析也固定使用随包 WASM，不访问在线二维码 API。
- 解析加载动画、阶段提示、减少动态效果、失败后同图重试、切换工作区和预览缓存恢复均完成回归。
- Electron 从 44.9.0 升至 44.9.1，修补受损中间证书信任问题；fast-uri 从 3.1.8 更新至 3.1.9，修复 URI 处理告警。
- 官网入口启用：[易码官网](https://w3f7-ezqr-tool.netlify.app/)。README 与官网补充独立解析说明、截图及新版下载。
- 原有文本生成、图片重构、保存、历史、设置和浅色玻璃外观保留。

# 易码 EzQR-Tools v7.4.0 · 透明 PNG 与 SVG

文本生成和图片重构现在可以输出白底 PNG、透明 PNG 或 SVG。新增独立「透明与矢量」工作区，用来给现有 PNG 去白底或描摹出 SVG。

- **生成与重构**：开始前选择格式，生成后可预览和下载，重构后自动保存。草料模式提供白底 PNG，另外两种格式在本地引擎下可选。
- **独立转换**：支持白底转透明、透明 PNG 转 SVG，以及白底一步转 SVG。可将当前透明结果接着矢量化，保留原图黑块的轮廓、位置和留白。
- **导出**：透明 PNG 只保留实心黑块。SVG 使用可缩放的几何路径。重构的新格式遇到重名会自动编号。

## 使用范围与验收

独立转换适用于纯黑白 PNG 或纯黑块配全透明背景的 PNG。碰到灰边、彩色或半透明像素，可先使用图片重构。透明二维码建议放在浅色背景并保留留白；SVG 与 PNG 的编码容量相同。

类型检查、Lint、109 项单测和 28 项 Electron 测试均通过，其中 1 项启动真实 Windows 打包版，验证断网导出、保存和原文回读。已知依赖告警及具体命令见 [交付与验收报告](https://github.com/PowerT-0704/EzQR-Tools/blob/v7.4.0/docs/releases/v7.4.0-validation.md)。[项目官网](https://w3f7-ezqr-tool.netlify.app/)

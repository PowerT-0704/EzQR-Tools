# 易码 EzQR-Tools v7.2.0

默认在本机完成图片解析、二维码重构、PNG 保存与历史记录，无需草料 API Key。
源码、安装器与校验文件通过 [GitHub v7.2.0 Release](https://github.com/PowerT-0704/EzQR-Tools/releases/tag/v7.2.0) 分发。

## 变更

- 引入固定版本 `zxing-wasm@3.1.6/reader`，仅检测二维码，启用旋转、反色和增强检测。
- 随应用打包 WASM，校验 SHA-256 后首次加载并复用；加载失败可重试，不访问 CDN、不自动上传。
- Chromium 将 PNG、JPG/JPEG、BMP、GIF、WebP 转为白底 PNG；动画读取首帧，保留原图预览与命名。
- “处理引擎”同时控制解析和生成。默认本地，明确选择草料在线后才上传原图和生成内容。
- 每个任务保留设置快照，避免设置防抖或延迟响应导致误上传；保留有效旧选择与 schemaVersion 2。
- 多码按位置排序并保留重复内容，重构首个并提示数量。文本原样保留，二维码容量、纠错与边框规则不变。
- 图片转换到保存全程防重复；无二维码、损坏图片、WASM 加载、容量与保存失败均可恢复。
- 历史写入成功后才提交内存状态，失败不产生成功记录；新增、下载路径更新和清空按队列写入。
- 保留浅色玻璃、胶囊滑块、独立弹窗、保存策略、GitHub 静默检查与手动接口检测。
- 修复本地解码模块与构建器生成的 `require` 声明冲突，增加产物语法及实际启动检查。

## 输入范围

二维码源图片最多 32 MiB，单边最多 8192 像素，总像素最多 16777216；转换 PNG 最多 64 MiB。
超限时提示裁剪或缩小，不静默缩放。这些限制不影响背景图片选择。

不增加单个二维码的文本容量，不提供文本网页托管，不改变旧配置中的有效草料选择。
手动接口检测和 GitHub 更新检查仍会联网；断网不阻塞本地核心功能。
